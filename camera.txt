Nvidia Jetson Orin Nano running Jetpack 7.2

1)	First check which port the camera is connected on by using
 – ls /dev/video*
2)	To get gstreamer to display say a webcam use – 
gst-launch-1.0 v4l2src ! autovideosink
This should display the image from the camera
3)	Install python
# Update system packages (be careful with spaces between sections of the command)
sudo apt update
# Install pip (Python package installer)
sudo apt install python3-pip v4l-utils -y
# Verify Python 3 is working
python3 –version
4)	Create a Python Virtual Environment (venv) to keep your coding clean and separated:
# Install the venv system core tool
sudo apt install python3-venv -y

# Create a virtual environment named 'cam_env'
python3 -m venv cam_env

# Activate your new environment
source cam_env/bin/activate

# Install OpenCV normally inside your environment
pip install opencv-python

need to run source cam_env/bin/activate every time you open a new terminal to run your camera script)

5)	Create a capture script
nano capture.py

6)	Install Yolo
source cam_env/bin/activate
pip install ultralytics

then need a python code

import cv2
from ultralytics import YOLO
# Load a lightweight, pre-trained YOLOv8 model (automatically downloads on first run)
model = YOLO("yolov8n.pt") 
# Open your Logitech C920 webcam
cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret: break
    # Run YOLO detection on the frame
    results = model(frame, stream=True)
    # Visualize the bounding boxes directly on the frame
    for r in results:
        annotated_frame = r.plot()
    # Display the live AI feed
    cv2.imshow("Jetson Orin Nano - YOLOv8", annotated_frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release()
cv2.destroyAllWindows()
