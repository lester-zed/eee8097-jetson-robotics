# README media assets

Portfolio-facing media used by the repository root `README.md` lives here.

## Current assets

```text
demo.svg
hardware_overview.svg
demo_frames/
```

- `demo.svg` is a lightweight looping sequence built from key frames of the recorded real-hardware execution.
- `demo_frames/` stores the selected source frames used by that sequence.
- `hardware_overview.svg` embeds the real platform photograph used in the README.

The root README intentionally keeps the media close to the project introduction so a recruiter can understand the physical system before reading the implementation details.

Optional future additions can include a system architecture figure or calibration-result plot when they add information not already conveyed by the engineering sections.
